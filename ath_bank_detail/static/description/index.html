Branch & IFSC Management

Enterprise-grade Banking Master Extension for Odoo

Overview

This module enhances Odoo’s standard Bank model by introducing structured Branch-level banking management with mandatory IFSC Code uniqueness, full audit tracking, and optimized display formatting.

Designed for enterprises that demand high data integrity, compliance readiness, and operational clarity in financial workflows.

Key Features

🔐 Data Integrity

  • Unique IFSC Code enforcement (SQL constraint)
  • Mandatory Branch Name field
  • Prevents duplicate banking records

📊 Smart Display Logic

  • Auto-generated Display Name
  • Format: Bank (Branch) – IFSC
  • Improved searchability & reporting

📝 Audit & Tracking

  • Integrated Chatter support
  • Field-level tracking enabled
  • Activity management support

How It Works

  1. Navigate to the Bank master form in Odoo.
  2. Enter the IFSC Code (system validates uniqueness).
  3. Add the Branch Name and optional address details.
  4. All changes are logged automatically in the Chatter.
  5. Display Name updates dynamically to structured format.
