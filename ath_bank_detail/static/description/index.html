Branch & IFSC Management for Odoo

Adds structured Branch details and IFSC Code management to Odoo Bank model with uniqueness enforcement and full change tracking.

Overview

This module extends the existing res.bank model in Odoo to introduce branch-level banking information and mandatory IFSC Code tracking.

It enhances the default Bank form and list views, enforces uniqueness of IFSC Codes at database level, and enables audit tracking through odoo chatter system.

Compatible with both Odoo Community and Enterprise editions.

Module Functionality

  • Adds Branch Name field (required)
  • Adds IFSC Code field (required)
  • Enforces unique IFSC Code via SQL constraint
  • Enables field-level tracking for key banking fields
  • Integrates Odoo Chatter (mail.thread & activity mixin)
  • Computes structured display name: Bank (Branch) - IFSC
  • Extends both Bank Form and Tree views

Technical Details

  • Model: res.bank
  • Inheritance: mail.thread, mail.activity.mixin
  • Database constraint for IFSC uniqueness
  • Computed display_name logic
  • Form and Tree view inheritance
  • No external API dependencies

Benefits

Improves banking master data structure, prevents duplicate IFSC entries, and provides better traceability of changes within Odoo.
