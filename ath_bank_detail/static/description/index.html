Branch & IFSC Management for Odoo

Adds structured Branch details and IFSC Code management to the Odoo Bank model with database-level uniqueness enforcement and full change tracking.

Overview

This module extends the existing res.bank model in Odoo to introduce branch-level banking structure and mandatory IFSC Code tracking.

It enhances the default Bank form and list views, enforces uniqueness of IFSC Codes at database level through an SQL constraint, and enables audit tracking using Odoo’s built-in chatter system.

Compatible with both Odoo Community and Enterprise editions.

Key Features

Unique IFSC Code

SQL constraint ensures each IFSC Code is unique within the system, preventing duplicate banking records.

Branch-Level Structure

Mandatory Branch Name field improves organization and clarity in bank master records.

Audit Tracking

Field-level tracking enabled using mail.thread and activity mixin integration.

Structured Display Name

Automatically formats display name as: Bank (Branch) - IFSC for better readability.

Technical Details

  • Model extended: res.bank
  • Inheritance: mail.thread and mail.activity.mixin
  • Database-level IFSC uniqueness constraint
  • Computed display_name logic
  • Form and Tree view inheritance
  • No external APIs or third-party dependencies

Benefits

Improves banking master data structure, prevents duplicate IFSC entries, enhances transparency through tracking, and keeps financial records well organized within Odoo.
