Branch & IFSC Management for Odoo

Enhance Odoo’s Bank model with structured Branch management, enforced IFSC uniqueness, and full audit tracking.

Overview

This module extends Odoo’s res.bank model to introduce branch-level banking structure and IFSC code management.

It ensures that every bank record includes a mandatory Branch Name and IFSC Code, prevents duplicate IFSC entries at the database level, and improves visibility through structured display formatting and audit tracking.

Fully compatible with Odoo Community and Enterprise editions.

Key Features

IFSC Code Management

  • Mandatory IFSC Code field
  • Database-level uniqueness constraint
  • Prevents duplicate IFSC records

Branch-Level Structure

  • Mandatory Branch Name field
  • Supports city and state details
  • Improves structured banking records

Smart Display Name

  • Auto-computed display format
  • Format: Bank (Branch) - IFSC
  • Improved search & readability

Audit & Tracking

  • Integrated Chatter support
  • Mail.thread enabled
  • Field-level change tracking

Technical Details

  • Extends existing res.bank model
  • Implements SQL constraint for IFSC uniqueness
  • Computed display name logic
  • Form & Tree view inheritance
  • Chatter and Activity mixin integration
  • Optimized for Odoo performance standards

Business Benefits

Maintain clean and structured banking master data, eliminate duplicate IFSC records, improve financial transparency, and enhance operational consistency across your Odoo system.
