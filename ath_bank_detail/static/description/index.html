Enhance your Odoo Bank Management with structured branch details and enforceable IFSC Codes. This module extends the default Odoo Bank model by introducing mandatory Branch support, unique IFSC Code enforcement, improved naming logic, and Chatter integration for full audit tracking.

Features

  • 📌 Ensure unique IFSC Codes via SQL constraint for data integrity.
  • 📌 Add and manage Branch Name directly on bank records.
  • 📌 Auto-generate a structured display name: Bank (Branch) - IFSC.
  • 📌 Support field tracking on IFSC, branch, state, city and other details via Chatter.
  • 📌 Seamlessly extend the existing Odoo bank tree and form views.
  • 📌 Improve searchability and usability with a clean structured view.

Configuration

After installation, go to the Bank Master (Accounting → Configuration → Banks). You will now see additional fields for Branch Name and IFSC Code. The IFSC field is mandatory and must be unique across all records in the system. The module automatically computes and displays the bank name with branch and IFSC for clarity in lists and reports.

How It Works

  1. Navigate to the Bank configuration form.
  2. Enter the IFSC Code and Branch Name.
  3. The system validates IFSC uniqueness and raises warnings if duplicates are found.
  4. Chatter logs and tracks all field changes for audit and traceability.
  5. The display name is auto formatted for all list and form views.
