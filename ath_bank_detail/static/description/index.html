Branch & IFSC Management for Odoo enhances your Bank Account master data with advanced banking details such as mandatory Branch Name and unique IFSC Code. This module ensures reliable banking data with strict uniqueness constraints, audit trail support, and powerful display formatting.

📌 Key Features

  • ✔ Enforce unique IFSC Codes to prevent duplicates via SQL constraint
  • ✔ Add and manage Branch Name directly on Bank records
  • ✔ Auto-generated display naming: Bank (Branch) - IFSC
  • ✔ Integrated chatter & activity tracking for full audit capability
  • ✔ Field-level tracking for IFSC, branch, address, state, city
  • ✔ Enhanced list and form views for structured bank data visibility
  • ✔ Optional geographical details: State & City

🔍 How It Works

This module seamlessly extends the standard Bank form. Once installed:

  • • Go to the Bank form
  • • Enter the IFSC Code and ensure its uniqueness
  • • Add the Branch Name and optional address fields
  • • All changes are tracked in the chatter for audit visibility
  • • The display name updates to Bank (Branch) – IFSC

🚀 Business Benefits

  • • Guarantees accurate and consistent banking data across your organization
  • • Reduces manual errors during financial transactions
  • • Improves usability & searchability in Bank master views
  • • Enables audit logs for compliance and traceability
  • • Ideal for multi-branch enterprises and finance departments

📦 Compatibility

Compatible with Odoo 14.0 to 19.0 and seamlessly integrates with all models related to Bank account, payments, invoices, and financial workflows.

⚙️ Installation & Setup

Simply install the module and navigate to the Bank form. New fields IFSC Code and Branch Name will appear under the Bank master. No additional configuration required.

📌 Notes

  • • IFSC Code must be unique across the system.
  • • Branch Name is a required field.
  • • Change tracking will appear in the chatter for audit history.
