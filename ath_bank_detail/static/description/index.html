Branch & IFSC Management for Odoo

Adds structured Branch details and IFSC Code management to the Odoo Bank model with uniqueness enforcement and full change tracking.

Overview

This module extends the existing res.bank model in Odoo to introduce branch-level banking information and mandatory IFSC Code tracking.

It enhances the default Bank form and list views, enforces uniqueness of IFSC Codes at database level, and enables audit tracking through Odoo’s built-in chatter system.

Compatible with both Odoo Community and Enterprise editions.

Key Features

🔐

Unique IFSC Code

SQL constraint ensures each IFSC Code is unique in the system.

🏦

Branch-Level Structure

Mandatory Branch Name field for better banking data organization.

📝

Audit Tracking

Field-level tracking enabled with chatter and activity support.

🔎

Smart Display Name

Auto-generated format: Bank (Branch) - IFSC for improved readability.

Technical Details

  • Model extended: res.bank
  • Inheritance: mail.thread & mail.activity.mixin
  • Database-level IFSC uniqueness constraint
  • Computed display_name logic
  • Form & Tree view inheritance
  • No external APIs or dependencies

Benefits

Improves banking master data structure, prevents duplicate IFSC entries, enhances traceability, and keeps your financial records organized within Odoo.
